# Personal Portfolio Website

A responsive personal portfolio website built using React and CSS. This portfolio presents my background, technical skills, certifications, learning journey, projects, and contact information.

## About the Project

This project was created to showcase my development progress and interests in different areas of information technology, including:

- Web Development
- Data Analytics
- Systems Administration
- Networking and Cybersecurity
- SAP and Enterprise Systems
- Cloud Infrastructure

The website uses reusable React components and props to organize and display information.

## Features

- Responsive navigation bar
- Fixed navbar while scrolling
- Introductory hero section
- Circular profile photo
- Downloadable CV
- About Me section
- Grouped technical skills
- Certifications section
- Education and learning journey
- Project cards
- GitHub, LinkedIn, Credly, and email links
- Responsive layout for desktop, tablet, and mobile devices

## Technologies Used

- React
- JavaScript
- JSX
- CSS
- HTML
- Git
- GitHub
- Vite
